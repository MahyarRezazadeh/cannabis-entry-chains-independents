## Known limitations of the run

* The optional rebuild from raw workbooks (`-Rebuild`) was not executed in this verification run because it calls the
  Census geocoder; the archived build files it would regenerate are those produced by the same scripts in 2026.
* The OSRM travel-time matrix is read from the cache; re-querying the public OSRM server can give slightly different
  durations if OpenStreetMap or the server's profile changes.
* Numerical results can differ in the last digit across platforms and library versions; all reported comparisons
  above are on the author's machine.
